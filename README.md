# CELL ATELIER

自动化细胞培养实验室的交互式概念演示。

- [进入交互实验室](https://gaohao16.github.io/cell-atelier/)
- [观看完整演示](https://gaohao16.github.io/cell-atelier/video.html)
- [MP4 视频文件](https://gaohao16.github.io/cell-atelier/cell-atelier.mp4)

页面支持自由旋转、缩放、平移，以及点击仪器后的固定近景动作演示。视频时长 7 分 30 秒，1600 × 900、24 fps、H.264，纯画面。

本项目展示自动化设备与样本流转的概念方案。设备几何、检测结果与运行状态均为演示内容，实际工程与生物学性能由独立验证确定。
