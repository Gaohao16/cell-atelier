# CELL ATELIER

Interactive automated cell-culture concept demonstration. Revision `20261110-transfer`.

[Interactive laboratory](https://gaohao16.github.io/cell-atelier/) · [Full silent video](video.html) · [External vial intake](transfer.html) · [Manual cryopreservation handoff](banking.html)

The pass-through chamber connects external human access to the internal robot. The outbound branch transfers untreated retained cells to a person for subsequent cryopreservation. It records human custody separately from completed freezing. The four-bucket centrifuge assembly references [Hettich documentation](https://www.hettichlab.com/downloadcenter/Products/Datasheets/ROTANTA-460-Robotic_EN.pdf); dimensions remain schematic. Device integration, biosafety, and biological performance require separate validation. Assay displays contain simulated data.
